# GroqReasoning

The published GroqReasoning ESP32 library baseline, included here so the source collection contains an installable Arduino library.

It sends structured reasoning requests to Groq and supports device/action mappings and contact aliases.

**Smart Patient Assistant integration status:** The agreed project-specific design still needs the next update: three separate AI-generated task summaries, pending-clarification resolution, and memory that records the actual execution outcome rather than just the proposed action. Do not treat this baseline alone as implementing those features.
