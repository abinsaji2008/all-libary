# All Libraries

Central repository for the libraries used by the Smart Patient Assistant project.

Each Arduino library will live in its own folder with `library.properties`, `src/`, and documentation as appropriate.

Planned libraries:
- `WakeNet9Arduino`
- `GroqAudioStream`
- `GroqReasoning`
- `GroqTTS`
- `WhatsAppAPI`
- `PatientController`
- `RGBLED`

Credentials such as Wi-Fi passwords, API keys, and real contact phone numbers must never be committed to this repository.
